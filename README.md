# 잉여 소재 다자간 순환 교환 시뮬레이션 (합성 데이터)

장기이식 교환(kidney exchange) 원리를 섬유 데드스톡 교환에 적용했을 때,
(1) 3자·4자 순환이 직접(2자) 교환보다 거래를 더 만드는가?
(2) 물류비·이탈 위험을 반영해도 참여 유인이 있는가?

## 5. 모델 요약
- 기업 N곳이 잉여 로트 1개씩 보유. 로트마다 소재 유형·정가 가치·무게·위치(서울 중심 5개 도시)가 있음.
- **수용 집합(Preference-based):** 기업 j가 받아들일 수 있는 로트 목록. 등급 강제 없이 유형·색상·품질 적합을 확률로 생성. 평균 수용 로트 수 `d`로 밀도 조절.
- **순환 청산(Multi-way):** 수용 그래프에서 2·3·4자 순환을 모두 열거하고, 겹치지 않게 기대 순이익 합이 최대인 조합을 정수계획(scipy `milp`)으로 선택.
- **경제성(Feasibility):** 참여자 순이득 = 받는 로트의 주관적 가치 − 내 로트의 외부 선택지(헐값 처분) − 내가 보내는 물류비. 크레딧 없는 경우 **전원이 0 이상**이어야 성사.
- **크레딧:** (a) `credit_list` = 정가 차이를 크레딧으로 정산(크레딧 가치는 현금의 80%), (b) `credit_surplus` = 순환 총이득이 0 이상이면 성사(이상적 상한).
- **이탈 위험:** 참여자당 실패 확률 p, 순환 성공 확률 (1−p)^k, 실패 시 물류비 일부 매몰.
- **기준선:** 가격 장터(판매자 호가, 구매자 지불의사 ≥ 호가+운송비, 최적 1:1 배정). 장터는 **현금 거래라 상호성 제약이 없는 유리한 기준선**입니다.

## 6. 실험과 연구질문 대응
| 실험 | 내용 | 대응 RQ |
|---|---|---|
| A | 메커니즘 비교(장터/2자/≤3/≤4/크레딧) | RQ1 |
| B | 밀도 d 스윕, 3자·4자 증분 | RQ2 |
| C | 순환 길이 상한 L × 이탈확률 × 물류비 | RQ3 |
| D | 물류비 배율에 따른 참여 가능 비율 | RQ4 |
| E | 참여 기업 수 N(임계 규모) | RQ6 |
| F, G | 가격 장터와의 비교(호가 수준, 탐색 마찰) | RQ5 보조 |

## 7. 주요 결과 (N=60, d=3, 40회 반복; 합성 가정 하에서의 결과)
- **순환이 직접 교환보다 많이 성사시킴:** 처리 로트 비율 2자 5.1% → ≤3자 8.7% → ≤4자 10.3% (A). 증분은 밀도에 따라 커짐: d=3에서 3자 +2.7pp, d=8에서 +16.1pp (B). d≤8 범위에서 역U형은 관찰되지 않았고 단조 증가였음(더 높은 d는 미검증).
- **다만 크레딧 없는 순수 물물교환은 약함:** 전원 개별 이득 조건 때문에 성사 가능 순환이 드뭄. 크레딧(정가차 정산)이 17.6%, 이상적 잉여 분배 시 23.5%로 가장 효과 큼.
- **L=4가 모든 (물류비×이탈확률) 조합에서 기대 순이익 최대** (C). 이탈 확률 20%까지 확인. 즉 이 가정 범위에서는 길이 상한을 3으로 제한할 이유가 약함. (더 긴 순환이나 더 큰 이탈 확률은 미검증)
- **참여 유인:** 물류비 배율 1→4배에서 순환 성사량 7.2%→4.3%, 전원 참여 가능 순환 비율 22.6%→13.0% (D). 크레딧 방식은 물류비 4배까지 거의 유지(20.6→18.8%).
- **규모:** 고정 수용 확률에서 N이 커질수록 순환 이득이 커지고 2자와의 격차도 벌어짐 (N=200: 2자 12.0%, 3자 25.3%) (E). N=20은 사실상 성사 없음 → 임계 규모 존재.
- **정직하게 밝혀야 할 불리한 결과:** 가격 장터가 탐색 마찰이 없으면 압도적으로 우세(44% vs 8.7%). 구매자가 판매 로트를 발견할 확률이 약 5~10% 이하로 낮을 때만 순수 물물교환(6.3%)이 장터와 비슷해지고, 크레딧 방식(15.3%)은 약 20% 근방까지 장터와 대등 (G). → **순환 교환은 장터의 대체재가 아니라, 탐색·신뢰 마찰이 큰 얇은 시장(thin market)의 보완재**로 주장하는 것이 데이터와 맞음.

## 8. 한계 (보고서에 반드시 명시)
1. 모든 파라미터(가치 분포, 외부 선택지 비율 30~70%, 물류비, 이탈 확률)는 **가정**이며 실측이 아님. 결론은 "이 가정 하에서"로 한정.
2. 수용 집합은 난수로 생성. 실제 수용 집합은 색상·촉감·인증 등으로 훨씬 구조적/희소할 수 있음.
3. 기업당 로트 1개, 단일 시점 청산(동적 도착, 반복 청산, 비동시 체인은 미구현).
4. 이탈은 독립 확률로 단순화. 전략적 허위 신고(strategy-proofness)는 미분석.
5. 장터 기준선은 단순 1:1 배정이며 협상·재고 분할 없음. 장터 결과는 탐색 마찰 가정(`visibility`)에 크게 의존.
6. 촉감·실물 검증은 모델링하지 않음.
7. 결과는 "합성 데이터 시뮬레이션"이며 "실증"이 아님.
